# 验收清单

## 网络基础

- [ ] 校园 Wi-Fi 下的 iPhone 和 Android 平板均获得可用 IPv6。
- [ ] 节点拥有公网 IPv6 和可用 IPv4 出口。
- [ ] 校园端能够主动连接节点指定端口。
- [ ] 节点重启后服务能够恢复，地址变化有 DDNS 处理。

## 安全

- [ ] 获得网络和设备使用授权。
- [ ] 未公开密码、私钥、令牌、订阅地址或完整公网 IP。
- [ ] 未关闭整机防火墙，只开放单个必要端口。
- [ ] 服务以低权限运行，配置和日志权限受控。
- [ ] 已准备停止服务、撤销规则和密钥轮换方案。

## A/B 计费验证

1. 记录测试前校园账户的流量、余额和时间。
2. 关闭转发方案，通过普通校园 IPv4 下载固定的 1 GB 测试文件，记录账户变化。
3. 等待计费数据刷新并记录结果。
4. 开启方案，确认出口 IPv4 已变为节点地址，再下载同一文件。
5. 再次等待计费数据刷新，比较两组数据。

为减少误差，应在相近时间段、相同设备、相同文件和相同 Wi-Fi 环境下测试。单次结果不代表长期政策，建议隔日复测。

## 性能验证

- [ ] 高峰和非高峰各测试 20–100 次延迟与丢包。
- [ ] 测试网页、视频和固定文件下载，而非只看测速峰值。
- [ ] 记录直连与转发后的延迟、吞吐和失败率。
- [ ] 手机和平板各持续使用至少 30 分钟，检查断连与耗电。

## 通过标准

只有同时满足以下条件，才可判定“当前环境下可用”：

- 校园账户计费对比符合预期；
- 高峰期速度和丢包可接受；
- 两类移动设备均能稳定连接；
- 节点没有暴露多余端口或敏感信息；
- 网络管理方和服务商条款允许该用途。

若其中任何一项不满足，应停止扩大使用并回退。不得把一次测试通过表述为“永久免流”。
