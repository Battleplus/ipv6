# 架构与选型

## 基本拓扑

```text
iPhone / Android 平板
        │ 校园 Wi-Fi（IPv6）
        ▼
校外双栈节点（公网 IPv6 + IPv4 出口）
        │ IPv4
        ▼
互联网目标站点
```

客户端通过 IPv6 连接校外节点，节点再代为访问 IPv4 资源。节点可以是 VPS，也可以是满足条件的校外固定电脑。

## 方案对比

| 选项 | 优点 | 必要条件 | 主要问题 |
|---|---|---|---|
| 双栈 VPS | 7×24 在线、网络和公网地址通常更稳定 | 明确提供公网 IPv6、允许相关用途、有 IPv4 出口 | 有服务器费用；流量与带宽可能另计费 |
| 家中固定电脑 | 可利用已有设备，成本较低 | 家宽有公网 IPv6、允许入站、路由器可配置、电脑不休眠 | 地址变化、断电、运营商入站限制 |
| 公司固定电脑 | 可利用持续在线设备 | 公司明确授权，网络服务条款允许，公网 IPv6 入站可达 | 安全与合规风险更高；企业防火墙常阻断入站 |
| 校园内电脑 | 配置方便 | 仍需要独立的校外 IPv4 出口 | 通常不能替代 VPS，流量仍从校园出口离开 |

## VPS 配置判断

转发少量个人流量通常不需要高计算规格，1 核/1 GB 或 2 核/2 GB 往往已足够。比 CPU 和磁盘更重要的是：

- 是否真正分配公网 IPv6；
- IPv6 是否允许主动入站；
- IPv4 出口、月流量和带宽限制；
- 距离校园的网络质量；
- 服务商使用条款。

阿里云轻量应用服务器的官方限制文档在调研时说明该产品不支持 IPv6，因此即使 2 核/2 GB、带宽和磁盘够用，也不适合本架构。购买前应再次核对最新产品说明，而不是只看配置页。

价格仅可作预算参考：促销型 VPS 可能约 70–220 元/年；主流国际厂商常见入门价约 30–50 元/月。价格和流量政策变化较快，以购买当日官方页面为准。DigitalOcean 调研时入门 Droplet 从 4 美元/月起，IPv6 地址本身不额外收费，但传输流量仍计入套餐。

## 手机与平板

- 小米 Android 平板可选择兼容目标协议的 Android 客户端；项目文档可能以 Clash Meta 类客户端为例。
- iPhone 需要 App Store 中兼容目标协议的客户端，部分客户端收费。
- 两端都必须在校园 Wi-Fi 下实际获得 IPv6；“设备支持 IPv6”不代表当前 Wi-Fi 已下发 IPv6。
- 配置文件或订阅地址属于敏感信息，不应公开分享。

## Windows 自建建议

若固定 Windows 电脑长期接入已获授权的公司网络，优先考虑 Hyper-V 中的 Ubuntu 虚拟机，并使用外部虚拟交换机。这样网络边界、服务管理和项目脚本兼容性通常比 WSL2 更清晰。

但在安装任何转发服务前，必须先完成入站 IPv6 验证。浏览器 IPv6 测试 10/10 只说明这台电脑能主动访问外部 IPv6，不说明校园设备能主动连接它。
